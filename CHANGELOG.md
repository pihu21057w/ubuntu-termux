## Changelog

## [3.0.0] - 2026-08-29

### Added
- Ubuntu 26.04 LTS (Noble Numbat) support
- Updated base system to Ubuntu 26.04
- Enhanced compatibility with latest packages and dependencies
- Improved system stability with latest LTS version
- **New Extra Features Installer Menu:**
  - LibreOffice Suite (Writer, Calc, Impress, Draw)
  - GIMP Image Editor
  - Thunderbird Email Client
  - Additional file managers (Nemo, PCManFM, Nautilus)
  - Development tools package (Python, Node.js, Java, Go, Rust, C/C++)
  - Docker CLI & Docker Compose
  - System monitoring tools (htop, btop, neofetch, ncdu)
  - Extended fonts collection (JetBrains Mono, Fira Code, Cascadia Code, etc.)
- **New Utilities Menu (utilities.sh):**
  - System information display
  - System update manager
  - Disk space cleaner
  - User settings backup tool
  - VNC resolution changer
  - Quick VNC help guide
- Interactive menu system for easier feature installation
- Automatic script downloading and execution
- Enhanced user experience with better prompts
- Color-coded terminal output for better readability
- Progress indicators for installations

### Changed
- Upgraded from previous Ubuntu version to 26.04 LTS
- Updated installation scripts to support Ubuntu 26.04
- Modified proot-distro configuration for Ubuntu 26.04
- Updated documentation to reflect Ubuntu 26.04 changes
- Improved gui.sh with extras installer prompt
- Enhanced user.sh to download all utility scripts
- Better organized script structure
- Improved error handling across all scripts

### Improved
- Installation process is now more modular
- Better package management
- Enhanced script organization
- More user-friendly menus and prompts
- Comprehensive system management tools
- Better documentation and help resources

### Notes
- This is a major version update to Ubuntu 26.04 LTS
- All existing features remain compatible with the new Ubuntu version
- Recommended to perform a fresh installation for best results
- New features can be installed post-setup using extras.sh
- Utilities menu accessible anytime via utilities.sh
